# DXRegia

Progetto indipendente basato su DXSpider Mojo. L'obiettivo è amministrare un nodo DX Cluster da un pannello web, con console classica e interoperabilità Telnet e nodo-nodo.

Per riprendere il lavoro, partire da [TASK.md](TASK.md). Le [istruzioni di progetto](AGENTS.md) valgono anche per Claude Code tramite [CLAUDE.md](CLAUDE.md).

Il codice DXSpider resta nei percorsi del clone upstream. Il nuovo codice vive in [dxregia](dxregia/README.md). Il nome DXRegia è un nome di lavoro.
